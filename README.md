# Recipe Book React App

## 1. Описание проекта

Recipe Book React App - это веб-приложение для поиска, просмотра, сохранения и управления рецептами. Проект состоит из клиентской части на React и серверной части на Express.

Пользователь может искать рецепты через внешний API, открывать подробную информацию о рецептах, получать случайный рецепт, добавлять рецепты в избранное, создавать собственные рецепты, редактировать и удалять их. Также реализован модуль генерации рецептов с помощью AI через интеграцию с GigaChat.

## 2. Как запустить проект

### Запуск front-end

```bash
cd front-end
npm i
npm run dev
```

### Запуск back-end

```bash
cd back-end
npm i
npm run dev
```

Для корректной работы приложения могут потребоваться переменные окружения:

- `VITE_API_KEY` - API-ключ для Spoonacular API.
- `VITE_BACKEND_API_URL` - адрес back-end API.
- `PORT` - порт back-end сервера, по умолчанию используется `3001`.
- Переменные для подключения GigaChat, если используется генерация AI-рецептов.

### Front-end

Front-end построен по модульному подходу, близкому к Feature-Sliced Design:

- `app` - глобальная настройка приложения, роутинг и стили.
- `pages` - страницы приложения.
- `widgets` - крупные UI-блоки, например layout, header и сетка рецептов.
- `features` - пользовательские действия и сценарии.
- `entities` - бизнес-сущности: рецепты, избранные рецепты, мои рецепты, AI-рецепты.
- `shared` - переиспользуемые API-клиенты, типы, константы, утилиты и UI-компоненты.

### Back-end

Back-end реализован на Express и отвечает за:

- хранение пользовательских рецептов;
- хранение избранных рецептов;
- хранение AI-рецептов;
- генерацию рецептов через GigaChat;
- чтение и запись данных в `db.json`.

## 5. Какие модули реализованы

В проекте реализованы следующие модули:

- Главная страница приложения.
- Поиск рецептов.
- Просмотр списка рецептов.
- Просмотр детальной страницы рецепта.
- Получение случайного рецепта.
- Избранные рецепты:
  - добавление рецептов в избранное;
  - просмотр списка избранных рецептов;
  - просмотр детальной страницы избранного рецепта;
  - удаление рецептов из избранного.
- Мои рецепты:
  - просмотр списка пользовательских рецептов;
  - создание нового рецепта;
  - просмотр детальной страницы своего рецепта;
  - редактирование своего рецепта;
  - удаление своего рецепта;
  - импорт рецепта в список пользовательских рецептов.
- AI-рецепты:
  - генерация рецептов по текстовому запросу;
  - просмотр списка AI-рецептов;
  - просмотр детальной страницы AI-рецепта.
- Общие UI-компоненты:
  - загрузчик;
  - сообщение об ошибке;
  - пустое состояние;
  - вводный блок страницы.
- Серверное API:
  - `/api/health`;
  - `/api/my-recipes`;
  - `/api/favorites`;
  - `/api/ai-recipes`;
  - `/api/ai-recipes/generate`.
